# Beekeeper Studio Plugins

This repo contains public plugins and themes for [Beekeeper Studio](https://github.com/beekeeper-studio/beekeeper-studio).

## Plugins
Plugins allow you to extend the functionality of Beekeeper with your own code. They run inside a secure iframe, can inherit styles from the app, and get access to an API so they can read certain data from your database. Internally we use this same system to power the AI Shell and ER Diagram features of Beekeeper. Check out the docs [here](https://docs.beekeeperstudio.io/plugin_development/) to get started building your own plugins.

## Themes
Themes let you customize the look and feel of the app to your heart's content. We provide a variety of variables for easy modification, but you can also get your hands dirty and write your own rules yourself. Check out the docs [here](https://docs.beekeeperstudio.io/theme_development/) to get started with themes.
